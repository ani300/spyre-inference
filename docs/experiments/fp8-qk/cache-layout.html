What the selected index means physically

The logical assignment is valid in PyTorch. In the current Spyre cache, the index selects a row outside the stick. For QFP8WT it also selects lanes inside each destination stick. A writer must preserve all other lanes. The current row-scatter path does not supply that partial-stick update.

For Granite at D = 128, the corresponding write changes 128 bytes total: one complete stick in the current cache, versus two bytes in each of 64 QFP8WT sticks. This counts destinations; it does not claim a measured 64× memory-traffic penalty or that the hardware can never support partial writes.

A solution could use a supported masked update, read/merge/write the affected sticks, or buffer complete 64-token tiles before packing them. The last option needs a separate path for the incomplete tail.
